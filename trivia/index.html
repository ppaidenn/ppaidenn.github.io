Local Trivia Night

Classic trivia without the impossible stuff.

Set up the players, choose the categories, spin the wheel, and play through a local question bank tuned for actual game-night use instead of obscure stumpers.

WelcomeHow it works

One screen, one wheel, six classic categories.

The setup keeps the same familiar flow: pick a roster, choose your play mode, set a target score, trim the category deck, set the order, and start spinning.

What changed

The old difficulty ladder is gone. This version uses a single curated classic bank so the questions feel closer to a living-room board game than a niche internet quiz.

Step 4Target

Choose the target score and decide whether a player must win by two.

Good defaults

Ten points with win-by-two turned on works well for longer games. Lower the target if you want a quicker round.
