What this page does

Pick a bracket creation path first. If you want help, this page can package up a request for Paiden. If you want to build it yourself, this page walks you into the Spotify tools needed to save the bracket into your paiden.com account.

Spotify browser mode uses Authorization Code with PKCE. That means this site only needs your Spotify Client ID. Do not paste a Spotify Client Secret into a website.
