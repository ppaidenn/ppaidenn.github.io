Spotify App Setup

This page walks you through the minimum Spotify developer setup needed for the self-serve bracket builder on paiden.com. You need Spotify Premium for this route.

Open Spotify Dashboard Back to Bracket Builder
STEP 1

Create the app

  1. Open the Spotify Developer Dashboard.
  2. Click Create app.
  3. Name it something like paiden bracket builder.
  4. Choose the Web API option.
STEP 2

Add the redirect URI

  1. Open your new app settings.
  2. Add this redirect URI exactly: https://paiden.com/tournaments/
  3. Save the settings.

You can also set the website field to https://paiden.com if Spotify asks for it.

STEP 3

Copy the Client ID only

  1. Copy the app’s Client ID.
  2. Go back to /bracket-builder/.
  3. Choose the self-serve Spotify option.
  4. Paste the Client ID into the builder and click Save.

Do not paste your Spotify Client Secret into the website. The paiden.com builder does not need it.

STEP 4

Connect and build

  1. Click Connect Spotify.
  2. Approve the Spotify sign-in screen.
  3. Paste a playlist you can access.
  4. Name the bracket and save it.
IMPORTANT

What this route requires

  • Spotify Premium on the account you sign in with.
  • Your own Spotify developer app.
  • A playlist that the signed-in Spotify account can read.
